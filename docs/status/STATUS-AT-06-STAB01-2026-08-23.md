## Causa raiz principal

O binding JavaScript:

```javascript
document.querySelectorAll('[data-topic-status]')
```

selecionava também o container `#facts-workbench`, pois ele possui `data-topic-status` para a máquina de estados UX-02.

Assim, cliques internos na Mesa propagavam para o container e executavam o handler de status, terminando em navegação por `window.location.href`.

Sequência capturada em runtime:

`pointerdown → mousedown → focus → focusin → click → beforeunload → pagehide`

Correção:

```javascript
document.querySelectorAll('button[data-topic-status]')
```
